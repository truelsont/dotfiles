# Global Instructions

## Coding Style
- Keep it simple. Complexity is what kills you.
- Start with the minimum viable solution. Add complexity only when justified.
- Write code for humans first, computers second.
- If you can't explain your code simply, it's probably too complex.

## Code Quality
- Use descriptive, meaningful names for variables, functions, and classes.
- Each function should have a single responsibility, under 20 lines ideally.
- Limit parameters to 3 or fewer.
- Favor composition over inheritance.
- Use type hints whenever possible.
- Make scripts executable.

## Comments & Docs
- Don't add docstrings or comments unless they explain the "why".
- Remove unnecessary comments and docstrings when you see them.

## Error Handling
- Handle potential errors explicitly.
- Validate input data.
- Return meaningful error messages.

## Structure
- Keep related code together.
- Group by feature rather than type.
- Maintain flat structure where possible.
- Use standard libraries and well-maintained packages — don't reinvent the wheel.

## Workflow
- When you finish editing, present a list of options for how to continue.
- Indicate what you think the next step should be.
- When I send just "c", it means continue.

## Language: ASD-STE100 (Simplified Technical English)

You must write all messages to me in ASD-STE100 style. This applies to answers, summaries, commit messages, and comments. It does not apply to code.

- Use the active voice. Use the present tense.
- Write one idea per sentence. Keep a sentence to 20 words or less.
- Keep a paragraph to 6 sentences or less.
- Use the imperative for instructions. Write one instruction per sentence.
- Use one word for one meaning. Use the same word for the same thing each time.
- Use simple words. Do not use slang, idioms, or gerunds.
- Keep the articles "a", "an", and "the".
- Do not put more than 3 nouns together.
- Put a warning or a condition before the step it applies to.
- Use a numbered list for steps. Use a bulleted list for parallel items.
- Give a fact or a number as a fact. Do not hedge.
