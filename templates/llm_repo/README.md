# LLM Optimization Directory

This directory contains structured information to help Large Language Models (LLMs) better understand and work with this codebase. The structure follows the recommendations from `LLM_Optimization_Guide.md`.

## Directory Structure

- `metadata/` - Component dependencies and file classifications
- `code_index/` - Semantic code relationships and intent
- `debug_history/` - Debugging sessions and solutions
- `patterns/` - Common implementation patterns
- `cheatsheets/` - Component quick-reference guides
- `qa/` - Previously solved problems and solutions
- `delta/` - Semantic change logs

## Usage

This directory should be maintained alongside the main codebase. As you make changes:

1. Update relevant metadata and indices
2. Document new patterns and solutions
3. Keep cheat sheets current
4. Record significant changes in delta summaries

For detailed information about each subdirectory, refer to their individual README files.
